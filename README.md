## Overview

Soundtoys Decapitator models five classic analog hardware devices—from Neve consoles to tape machines—delivering a range of saturation, harmonic enhancement, and subtle to extreme distortion.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys Decapitator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Five Styles** | A (Ampex), E (EMI), N (Neve), T (transformer), P (preamp) saturation modes |
| **Tone Control** | High-frequency tilt control shapes the saturation character |
| **Punish Mode** | Extremely aggressive drive for lo-fi and destruction effects |
| **Mix Knob** | Wet/dry blend enables parallel saturation processing |
